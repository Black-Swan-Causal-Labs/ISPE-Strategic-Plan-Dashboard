# ISPE Strategic Plan Dashboard — public deploy

This branch (`public-deploy`) contains **only** the public-facing dashboard, ready to be
served by GitHub Pages and embedded on the ISPE website as an `<iframe>`.

## What's on this branch
- `index.html` — the public dashboard (reads `data.json`; carries an embedded fallback copy
  that renders a loud "these figures are out of date" banner if the fetch fails)
- `data.json` — plan progress data, **generated**, not hand-edited (see below)
- `ispe-emblem.png` — the header emblem. A transparent PNG whose white brushed ring only
  reads against the dark header; it must never be given a white background
- `banner picture.jpg` — the header photograph
- `fonts/` — self-hosted Source Serif 4 (SIL OFL 1.1)

The admin editor (`admin.html`), the survey ingest (`csv_to_dashboard_json.py`) and the
payload builder are intentionally **not** on this branch, so they are never published to the
public site. They live on `main`.

## `data.json` here is not the same file as on `main`

The working `data.json` on `main` carries per-tactic **notes** — free text committees write
for internal reporting, not for publication. Removing the Notes column from the page would not
have made them private, because `data.json` is fetched over HTTP and can be read directly.

So the copy on this branch is generated by `build_public_payload.py` (on `main`), which strips
those fields and refuses to emit a file that still contains them. **Never copy `data.json`
straight across from `main`.**

## Deploy with GitHub Pages
Repo → **Settings → Pages → Build and deployment**:
- **Source:** Deploy from a branch
- **Branch:** `public-deploy` — folder `/ (root)` → **Save**

The site publishes at `https://<account>.github.io/<repo>/`. First build takes ~1 minute.

## Embed on the ISPE website
Paste the responsive iframe snippet from the handoff notes into the page where the dashboard
should appear, pointing `src` at the Pages URL above. The snippet never changes, however often
the data is updated.

## Updating the data
From `main`, with the new survey ingested and reviewed:

```bash
python3 build_public_payload.py -o /tmp/public-data.json   # strips internal fields
python3 build_public_payload.py --check /tmp/public-data.json   # must exit 0
```

Then on this branch: bring `index.html` across from `main`, drop the generated `data.json` in,
and confirm before pushing that no admin surface came with it — no `admin.html`,
`admin-server.py`, `csv_to_dashboard_json.py` or `build_public_payload.py`, and no
"Admin Control Panel", "publishReadOnly", "atRiskPanel" or "notes-input" anywhere in
`index.html`. GitHub Pages redeploys within a minute.
